# Project Structure Explanation

## Overview

This is a smart contract escrow system with a REST API that automatically runs security analysis before creating deals. Here's what everything does:

## Directory Structure

```
creator-escrow/
├── contracts/              # Smart contracts (Solidity)
├── test/                   # Test files
├── scripts/                # Deployment and utility scripts
├── api/                    # REST API server
├── .github/                # CI/CD configuration
├── artifacts/              # Compiled contracts (auto-generated)
├── cache/                  # Hardhat cache (auto-generated)
└── node_modules/           # Dependencies (auto-generated)
```

## Core Files Explained

### 📄 `contracts/` - Smart Contracts

**`CreatorCheckoutEscrow.sol`**
- **What it does:** Main escrow contract
- **Key features:**
  - Consumer deposits price → Store receives it
  - Store deposits commission → Influencer receives it
  - Auto-releases when both parties fund
  - Owner can refund if needed
- **Functions:**
  - `createDeal()` - Creates new escrow deal
  - `fundConsumer()` - Consumer deposits price
  - `fundStore()` - Store deposits commission
  - `refund()` - Owner refunds if deal incomplete

**`MockUSDC.sol`**
- **What it does:** Mock USDC token for testing
- **Why:** Real USDC requires mainnet deployment, this lets us test locally
- **Features:** 6 decimals (like real USDC), mintable for testing

### 🧪 `test/` - Tests

**`escrow.test.js`**
- **What it does:** Automated tests for the escrow contract
- **Tests:**
  1. Auto-release when both parties fund
  2. Auto-release when consumer funds after store
  3. Owner refund functionality
  4. Unauthorized access prevention
- **Run with:** `npm test` or `npx hardhat test`

### 📜 `scripts/` - Utility Scripts

**`deploy.js`**
- **What it does:** Deploys contracts to blockchain
- **Usage:** `npx hardhat run scripts/deploy.js --network localhost`
- **Output:** Contract addresses (save to `.env` as `ESCROW_ADDRESS`)

**`kairo-analyze.sh`**
- **What it does:** Runs Kairo security analysis on contract
- **Usage:** `./scripts/kairo-analyze.sh`
- **Requires:** `KAIRO_API_KEY` in environment
- **Output:** Security decision (ALLOW/WARN/BLOCK)

**`kairo-deploy-check.sh`**
- **What it does:** Final security check before deployment
- **Usage:** `./scripts/kairo-deploy-check.sh <chain_id> <network>`
- **When to use:** Right before deploying to testnet/mainnet

### 🌐 `api/` - REST API Server

**`server.js`**
- **What it does:** Express.js REST API server
- **Main endpoint:** `POST /api/create-escrow`
- **Features:**
  - Accepts JSON with price, commission, wallet addresses
  - Automatically runs Kairo security analysis
  - Creates escrow deal on blockchain
  - Logs errors to `errors` file
- **Start with:** `npm run api`
- **Port:** 3000 (default)

### ⚙️ Configuration Files

**`package.json`**
- **What it does:** Project dependencies and scripts
- **Key scripts:**
  - `npm run compile` - Compile contracts
  - `npm test` - Run tests
  - `npm run api` - Start API server
  - `npm run deploy` - Deploy contracts

**`hardhat.config.js`**
- **What it does:** Hardhat (development framework) configuration
- **Contains:** Solidity version, network settings, compiler options

**`.env`** (create this file)
- **What it does:** Environment variables (secrets, config)
- **Required:**
  - `KAIRO_API_KEY` - Your Kairo API key
  - `ESCROW_ADDRESS` - Deployed contract address
- **⚠️ Never commit this file!** (already in `.gitignore`)

**`.gitignore`**
- **What it does:** Files to exclude from git
- **Includes:** `node_modules/`, `.env`, `artifacts/`, `errors`, logs

### 🔄 `.github/workflows/` - CI/CD

**`kairo-security.yml`**
- **What it does:** GitHub Actions workflow
- **When it runs:** On every pull request
- **What it does:**
  1. Checks out code
  2. Runs Kairo security analysis
  3. Blocks PR if Kairo returns BLOCK/ESCALATE
- **Setup:** Add `KAIRO_API_KEY` to GitHub Secrets

### 📝 Documentation

**`README.md`**
- **What it does:** Complete project documentation
- **Contains:**
  - Quick start guide
  - API usage examples
  - Setup instructions
  - Contract details

## Auto-Generated Files (Don't Edit)

**`artifacts/`**
- Compiled contract bytecode and ABIs
- Generated by: `npx hardhat compile`
- **Purpose:** Needed to interact with contracts

**`cache/`**
- Hardhat compilation cache
- **Purpose:** Speeds up recompilation

**`node_modules/`**
- All npm dependencies
- **Purpose:** Libraries and tools
- **Size:** Large (don't commit to git)

**`errors`**
- Error log file
- **Purpose:** All API errors logged here
- **Format:** JSON lines with timestamps

## How Everything Works Together

### Development Flow

1. **Write Contract** → `contracts/CreatorCheckoutEscrow.sol`
2. **Compile** → `npm run compile` → Creates `artifacts/`
3. **Test** → `npm test` → Runs `test/escrow.test.js`
4. **Deploy** → `npm run deploy` → Uses `scripts/deploy.js`
5. **Start API** → `npm run api` → Runs `api/server.js`

### API Request Flow

```
Client sends JSON
    ↓
api/server.js receives request
    ↓
Validates input (price, commission, addresses)
    ↓
Calls Kairo API (scripts/kairo-analyze.sh or direct)
    ↓
If Kairo passes → Creates deal via contracts/CreatorCheckoutEscrow.sol
    ↓
Returns dealId and transaction hash
    ↓
If error → Logs to errors file
```

### Production Deployment Flow

1. **Code pushed to GitHub**
2. **GitHub Actions runs** → `.github/workflows/kairo-security.yml`
3. **Kairo analysis** → Blocks PR if unsafe
4. **Merge PR** → Code is safe
5. **Deploy** → `scripts/deploy.js` to testnet/mainnet
6. **Pre-deploy check** → `scripts/kairo-deploy-check.sh`
7. **Deploy** → Contracts live on blockchain

## Key Concepts for New Teammates

### Smart Contract
- Lives on blockchain (Ethereum, etc.)
- Handles escrow logic
- Auto-releases funds when both parties deposit

### REST API
- HTTP server that accepts JSON
- Creates deals on blockchain
- Runs security checks automatically

### Kairo Security
- Third-party security analysis
- Scans contract for vulnerabilities
- Returns ALLOW/WARN/BLOCK decision

### Error Logging
- All errors go to `errors` file
- Includes timestamp, request data, error details
- Helps debug issues

## Common Tasks

**Add new contract function:**
1. Edit `contracts/CreatorCheckoutEscrow.sol`
2. Run `npm run compile`
3. Update `test/escrow.test.js` with test
4. Run `npm test`

**Change API behavior:**
1. Edit `api/server.js`
2. Restart: `npm run api`

**Deploy to new network:**
1. Update `hardhat.config.js` with network config
2. Run `scripts/kairo-deploy-check.sh` first
3. Run `scripts/deploy.js --network <network>`
